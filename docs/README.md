# Docs

Đây là folder lưu trữ tài liệu của dự án.

# Cấu trúc của `docs/`

```Tree
docs/
├── README.md
├── benchmarks/             # Folders chứa benchmarks của dự án
├── internals/              # Folders chứa tài liệu nội bộ, bao gồm
│                           # thiết kế, kiến trúc, yêu cầu, v.v của
│                           # dự án
└── refs/                   # Tài liệu tham khảo
```
